# AI-Based Suspicious Behavior Detection System

An AI-powered suspicious behavior detection system developed as an undergraduate graduation project.

## Team Members
- Esmanur Türkmen
- Bilge Aykan

## Project Features
- Person detection using YOLO
- Pose estimation with MediaPipe
- Suspicious behavior analysis
- Fall, Run and Fight detection
- Secure encrypted logging
- Web-based monitoring interface

## Technologies
- Python
- OpenCV
- YOLO
- MediaPipe
- Computer Vision
- Artificial Intelligence
- Cyber Security
